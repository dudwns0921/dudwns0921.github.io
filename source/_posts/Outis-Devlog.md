# 게임 소개

Outis는 영화 《오디세이》와 그 원작인 호메로스의 『오디세이아』 중 외눈 거인 폴리페모스 에피소드를 바탕으로 만든 3인칭 어드벤처 게임이다. 제목은 오디세우스가 폴리페모스에게 댄 가짜 이름으로, "아무도 아니다"라는 뜻을 가지고 있다.

| | |
|---|---|
| 장르 | 3인칭 어드벤처 |
| 엔진 | Godot 4.7 |
| 사용 도구 | Claude Code, Godot MCP Pro, Meshy AI, ElevenLabs, ChatGPT |
| 배포 | itch.io (Windows, macOS / 한국어, English) |

치즈를 훔쳐 먹다 들킨 오디세우스와 선원 열두 명이 거인의 동굴에 갇히고, 거인은 저녁마다 선원을 둘씩 잡아먹는다. 플레이어는 선원이 다 먹히기 전에 잠든 거인 곁을 몰래 오가며 무기를 만들어 탈출해야 한다.

진행 순서는 영화와 원작을 조금씩 섞어서 짰다.

```
몽둥이 잘라내기 → 다듬기 → 선원 풀기 → 불 살리기 → 달구기 → 눈 찌르기 → 탈출
```

탈출한 뒤에는 배 위에서 거인에게 진짜 이름을 외칠지 말지를 고르게 되고, 이 선택에 따라 엔딩이 갈린다.

## GDD와 코드 동기화

이번에도 해커톤 때와 마찬가지로 GDD를 게임의 기반으로 삼았다. 그때도 GDD에 가장 신경을 쓰긴 했지만, 이번에는 좀 더 체계를 갖춰서 진행해 보고 싶었다.

그래서 첫날에 `gdd-sync`라는 스킬부터 만들었다. GDD와 코드가 서로 어긋나지 않게 맞춰주는 스킬인데, 원리는 간단하다. GDD와 코드 양쪽에 같은 ID를 붙여두는 것이다.

GDD 맨 뒤에 아래와 같은 표를 두고,

```markdown
| ID | 값 | 출처 | 코드 위치 | 상태 |
|---|---|---|---|---|
| BAL.CREW.START | 12 | 4.3 | game/config/balance.gd:CREW_START | 동기 |
| BAL.CREW.FREE_SEC | 4 | 4.5 | game/config/balance.gd:CREW_FREE_SEC | 동기 |
```

코드에서는 해당 값을 정의하는 줄에 주석으로 ID를 적어둔다.

```gdscript
static var CREW_START := 12  # GDD: BAL.CREW.START
static var CREW_FREE_SEC := 4.0  # GDD: BAL.CREW.FREE_SEC
```

스킬을 실행하면 파이썬 스크립트가 표와 주석을 대조해서 값이 다른 항목, 아직 구현되지 않은 항목, 표에는 없는데 코드에만 있는 항목을 찾아준다. 여기에 방향을 지정해서 `/gdd-sync to-code`를 실행하면 GDD를 기준으로 코드를 고치고, `/gdd-sync to-gdd`를 실행하면 반대로 코드를 기준으로 GDD를 고친다.

최종적으로 이 표에는 253개 항목이 들어갔다. 만드는 동안 순서가 바뀌기도 하고 아이템이 통째로 빠지기도 했는데, 그때마다 문서와 코드가 같이 바뀌어서 기획서를 끝까지 믿고 볼 수 있었다.

## 밸런스 조정

게임을 만들면서 가장 시간이 많이 든 건 밸런스였다. 값을 바꾸고, 플레이해 보고, 다시 바꾸는 과정을 계속 반복해야 했기 때문이다. 그때마다 Claude에게 "달리기 소음을 낮춰줘"라고 요청하는 것도 번거로웠고, 수치가 코드 곳곳에 흩어져 있어서 전체 밸런스가 어떤 상태인지 한눈에 파악하기도 어려웠다.

고민 끝에 밸런스 수치 111개를 엑셀 파일 하나로 빼기로 했다. 엑셀에서 값을 고치고 저장하면 실행 중인 게임이 0.5초 안에 파일을 다시 읽어서 바로 반영한다. 덕분에 게임을 켜둔 채로 값을 바꿔가며 테스트할 수 있게 되었고, 모든 수치를 표 하나에서 볼 수 있게 되었다.

![밸런스 표](balance-xlsx.png)

값이 확정되면 엑셀의 값을 코드에 반영하고, 앞서 만든 `gdd-sync`로 GDD까지 맞춘다.

## HUD 대신 몰입감

맨 처음에는 HUD에 많은 정보를 띄우려고 했다. 폴리페모스의 민감도나 모닥불 연료처럼 게임에 필요한 수치들을 화면에 잔뜩 올려놨었다. 그러다 게임 안에서 무엇이 더 자연스러울지 고민해 봤고, 수치를 보여주기보다 위험도를 감각으로 전달하는 편이 내가 오디세우스가 된 듯한 몰입감을 줄 수 있겠다고 생각했다.

그래서 비네팅 효과와 심장 소리를 넣어, 위험이 커지고 있다는 걸 시각과 청각으로 느낄 수 있게 했다. 최종적으로는 아래와 같은 형태가 되었고, 오디세우스의 상태를 나타내는 표시는 HUD에서 전부 제거했다.

## 에셋

### 캐릭터

캐릭터는 해커톤 때 동료에게 배운 파이프라인을 그대로 활용했다. Claude로 내가 원하는 캐릭터의 프롬프트를 뽑고, ChatGPT의 이미지 생성으로 컨셉 이미지를 만든 뒤, 그 이미지를 Meshy AI에 넘겨 3D 모델을 생성하는 방식이다.

![폴리페모스 컨셉](concept-polyphemus.png)

다만 에셋에 너무 많은 시간을 쓰지는 않았고, 어느 정도 나왔다 싶으면 거기서 멈췄다. 지난 해커톤 때 에셋에 몰입하다가 정작 중요한 부분을 놓쳤던 경험이 있었기 때문이다.

### 컷신

컷신은 고대 그리스 도자기 그림 스타일로 만들었다. 이 이야기를 호메로스가 노래로 전한다는 설정이라, 후대에 도자기에 그려진 장면처럼 보이면 어울리겠다고 생각했다.

# 마치며

해커톤 때는 40시간이라는 제한이 있어서 어떻게든 끝을 낼 수 있었다. 이번에는 끝을 내가 정해야 했는데, 고치고 싶은 부분이 계속 눈에 들어와서 오히려 그게 더 어려웠다. 결국 0.1이라는 버전을 붙여 일단 올리고 나서야 한숨 돌릴 수 있었다.

그래도 만드는 내내 진심으로 재밌었다. 머릿속으로 상상하던 세계가 조금씩 구체화되는 과정은, 이유는 잘 모르겠지만 나에게 즐거움과 충만함을 주는 것 같다.
